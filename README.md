# 🏥 Medicare Hospital

 **A modern, responsive and user-friendly hospital website built to provide a smooth digital healthcare experience.**

Medicare Hospital is a clean and professional healthcare website where users can explore hospital services, doctors, appointments, FAQs and contact information.

## ✨ Features

* 🏠 **Home & About Hospital**
* 🩺 **Medical Services**
* 👨‍⚕️ **Doctors Information**
* 📅 **Appointment Booking**
* ❓ **FAQ Section**
* 📞 **Contact & Location**
* 🚑 **Emergency Services**
* 📱 **Fully Responsive Design**
* 🎨 **Modern Healthcare UI**

## 🛠️ Tech Stack

| Technology     | Purpose           |
| -------------- | ----------------- |
| 🌐 HTML5       | Website Structure |
| 🎨 CSS3        | Styling & Design  |
| ⚡ JavaScript   | Interactivity     |
| 🅱️ Bootstrap  | Responsive UI     |
| ⭐ Font Awesome | Icons             |

## 🚀 Getting Started

```bash
git clone https://github.com/Ankitpandeyup51/Medicare_Hospital.git
```

Then open **`MedicareHospital.html`** in your browser.
